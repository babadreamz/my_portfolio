# Portfolio - Shima Hilary Kaior

Personal portfolio of Shima Hilary Kaior, Backend Engineer (Java, Spring Boot, Go, PostgreSQL).

Live at [shimakaior.xyz](https://shimakaior.xyz)

## Stack

- React 18 + Vite
- Framer Motion for animations
- EmailJS for the contact form
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```
